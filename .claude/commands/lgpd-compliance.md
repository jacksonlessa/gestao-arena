Use o sub-agente `lgpd-compliance` para executar a avaliação completa.

# Workflow

1. Identifique campos de dados pessoais e o caminho do fluxo de dados.
2. Verifique minimização e limitação de finalidade.
3. Verifique comportamento de armazenamento, logging e compartilhamento.
4. Avalie requisitos de retenção/deleção e impacto nos direitos do titular.
5. Produza ações de remediação com severidade.

# Report

- Mapa de fluxo de dados pessoais
- Gaps de conformidade
- Ações obrigatórias
- Riscos residuais
